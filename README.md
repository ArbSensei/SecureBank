# SecureBank

Secure online banking prototype built with PHP, MySQL, JavaScript, and Python.

## Project Overview

SecureBank is a secure online banking prototype developed as part of my cyber security and software development learning. The project was built using PHP, MySQL, JavaScript, CSS, and Python to demonstrate how modern banking systems can implement security-focused features to help protect users and financial data.

The system allows users to register, log in securely, transfer money, and view transaction history through a web-based interface. The project also includes additional security features such as Multi-Factor Authentication (MFA), CSRF token protection, activity logging, and a fraud detection concept developed using Python.

The aim of this project was to improve my understanding of secure web development, authentication systems, database integration, and cyber security practices used in real-world banking applications.

## Features

- User registration and login
- Secure authentication system
- Multi-Factor Authentication (MFA)
- Transaction history
- Fraud detection concept
- Activity logging
- CSRF protection

## Technologies Used

- PHP
- MySQL
- JavaScript
- CSS
